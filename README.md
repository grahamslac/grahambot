# grahambot
Graham Bot es un bot de Telegram de criptoanálisis que recopila datos reales de criptomonedas, analiza mercados, históricos, volumen, liquidez, holders y riesgos mediante algoritmos. Genera métricas, gráficas y un scoring explicable, utiliza IA para interpretar resultados y envía alertas e informes automáticamente, sin realizar compras ni ventas.
